# IZ1 经典关卡导入器

这是一个 Lua 资源包模组。启用后，屏幕左侧会出现可拖动的 `IZ1` 悬浮按钮。打开面板并粘贴经典 IZ1 关卡代码，模组会在 Lua 中完成解析、校验与 JSON 文本拼接，再通过 `CreativeLevelManager.AddDIYLevelJson` 保存到游戏的 `levels` 目录。

导入成功后，重新进入“创意关卡”页面即可看到关卡；模组不会自动进入关卡。

## 安装

将整个 `iz1_level_importer` 文件夹复制到游戏的资源包目录，在游戏设置的资源包管理中启用，然后重启游戏。

## 支持内容

- 红线、初始阳光和 0～10 个卡槽
- 植物及原版僵尸卡
- 固定植物、墓碑、弹坑、梯子和钉耙
- 两个黄色传送门和两个蓝色传送门
- 忽略 IZ1 文本中的所有空白字符

导入关卡默认使用 `Background: 1` 和 IZ 关卡图标 `Icon: 11`。

墓碑、弹坑、梯子、钉耙和传送门分别通过 `SpawnGraveStone`、`SpawnCrater`、`SpawnLadder`、`SpawnRake` 和 `SpawnPortal` 组件导入，保留 IZ1 代码中的精确坐标及重复项。导入弹坑不指定时间，使用组件默认值 `2147483647`。

精华版当前棋盘最多为 9 列、6 行。IZ1 格式虽然还能编码第 10 列或第 7 行，但模组会对这些无法在目标棋盘中还原的坐标明确报错，不会生成残缺关卡。

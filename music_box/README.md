# Lua 音乐盒示例资源包

这是一个可直接导入的目录式资源包示例。启用 Lua 脚本后，屏幕左上角会出现一个可拖动的留声机按钮，并在主界面、棋盘及其他界面中持续显示；点击按钮会打开宽度为 860、高度为 548 的石碑音乐盒窗口。

窗口左侧用滚动区域列出从 `MusicTune` 动态收集的可播放曲目，鼠标停在曲目按钮上时也可以直接滚动。右侧显示当前曲目、真实播放进度、鼓点开关，以及上一首、暂停/继续、下一首和停止按钮。鼓点开关沿用游戏在 `Board` 中使用的 burst 状态机，因此鼓轨会按原有规则同步并渐入、渐出；手动选择会跨界面保持，点击停止后恢复由 `Board` 自动控制鼓点。

脚本不会把以下内部值列入曲目列表：

- `None`
- `MainMusic`
- `Drums`
- `Hihats`
- `MusicTuneCount`
- `DrumBase`

其中 `None` 表示没有曲目，其余值用于内部 MO3 主轨、鼓轨、高帽轨、枚举计数或鼓轨偏移，不应作为普通曲目单独播放。

## 使用方法

1. 将整个 `music_box` 文件夹压缩为 ZIP。
2. 在游戏资源包界面导入并启用。
3. 开启该资源包的“启用 Lua 脚本”开关并确认安全提示。
4. 重启游戏，在任意界面点击左上角的留声机。

示例自带 `images/phonograph.png`，它覆盖同名的 `IMAGE_PHONOGRAPH`，让原本属于延迟加载资源组的留声机图片可以在任意界面立即使用；关闭资源包后会恢复游戏原资源。

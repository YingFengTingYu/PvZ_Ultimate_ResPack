# 动态掉落物 Lua 模组

这是一个可直接导入的目录式资源包示例。它注册一个独立的动态掉落物：

- 正常击杀僵尸时掉落一个金锭图标；
- 掉落物使用原生 `CoinMotion.Coin` 抛出、落地和过期流程；
- 点击掉落物后，通过 `Coin.Collect` hook 增加 25 阳光；
- 掉落物本身不继承金币、阳光、奖品或解锁物的原生奖励逻辑。

动态掉落物没有 `base_type`。`image` 只决定外观，奖励和特殊行为应通过 `Coin.CoinInitialize`、`Coin.Collect`、`Coin.Die` 等 hook 实现。首版不支持联机同步。

使用方法：

1. 将整个 `dynamic_coin_example` 文件夹压缩为 ZIP。
2. 在游戏的资源包界面导入并启用该资源包。
3. 在“设置 - 资源包”中开启“启用 Lua 脚本”。
4. 重启游戏并进入普通关卡，击杀僵尸后点击掉落的金锭图标。
